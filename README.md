# 🏎️ F1 Telemetry Dashboard

Um dashboard interativo em front-end desenvolvido para acompanhar estatísticas, classificação e dados da Fórmula 1 em tempo real. 

Desenvolvido como parte do meu avanço no curso técnico de Informática para Internet, este projeto une o estudo prático de desenvolvimento web com o automobilismo. O objetivo é consumir dados brutos de telemetria e resultados, transformando-os em uma experiência visual limpa e responsiva.

## 🚀 Funcionalidades

- **Classificação em Tempo Real:** Tabela com a pontuação do campeonato de pilotos e construtores.
- **Calendário da Temporada:** Exibição das corridas e horários.
- **Cards de Pilotos:** Informações detalhadas consumidas via API.
- **Design Responsivo:** Interface adaptada para funcionar em celulares e desktops.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox/Grid)
- JavaScript (ES6+ e consumo de APIs via `fetch`)

## 💡 Aprendizados e Foco Técnico

O foco principal deste repositório é demonstrar o domínio sobre o ecossistema front-end sem a dependência de um banco de dados próprio. Os principais desafios incluem:
1. Tratamento de requisições assíncronas (Async/Await) e erros em APIs externas.
2. Manipulação dinâmica do DOM para renderizar componentes na tela a partir de arquivos JSON.
3. Boas práticas de UI/UX e estruturação de interface.
